#### Combustion & Emission Characteristics for Alcohol Fuels



| Combustion                 | Performance                               | Emission |
| -------------------------- | ----------------------------------------- | -------- |
| 1. HRR (Heat reset rate)   | 1. BTG (brake thermal efficiency)         | 1. CO    |
| 2. Pressure Vs Crank angle | 2. BSEC Brake specific energy consumption | 2. HC    |
| 3. Combustion Duration     | 3. Indicated Power                        | 3. NOX   |
| 4. Ignition Delay          | 4.Meen                                    | 4. PM    |
|                            |                                           | 5. Smoke |
|                            |                                           | 6. O2 %  |

$$
\text{Break Power} = \frac{2\pi NT}{60}
$$
where N - RPM of the Engine,
T - Torque produced by engine in NM 


$$
T_{e} = \frac{n_{c}V_{d}P_{me}}{2\pi n_{r}} 
$$
$n_{c}$ number of cylinder.
$V_{d}$ cylinder volumetric displacement.
$P_{me}$(pa) - Mean Effective Pressure.
$n_{r}$ - Number of crankshaft rotation for a complete engine cycle.
