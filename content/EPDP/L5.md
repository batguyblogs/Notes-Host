#### Intro to control Panels
dfn: A control panel is a flat surface are that houses the instruments and controls of a system

applications: industrial automation, power systems, HVAC, heating/ ventlation/ air conditioning etc.

Importance: Centralizes control improves safety and simplifies maintanence

- How HVAC is Organized within a Control Panel:
**Sensors**:
HVAC systems utilize various sensors ( temp humidity pressure etc) to monitor environmental conditions 
**Controllers:** 
- these sensors feed data to controllers which are the brains of the hvac system
actuators:
Controllers then activate actuators like dampers fans valves to adjust the HVAC equipment and maintain desired conditions

User Interface:
The control panel provides a user interface allowing operators to monitor and adjust the systems  in one unified place

PLCs and DCSs are essential components in industrial automation, responsible for controlling and monitoring various processes

- A PLC is a ruggedzied computer that acts as the brain of a machine or process, controlling its operations based on programmed logic
- An HMI is a user interface that allows operators to interact with the PLC and the machine, providing real-time data visualization and control capabilities.
