This is a popular workplace organisation method build on the 5S's 

| Japanese | Translation         | American                           |
| -------- | ------------------- | ---------------------------------- |
| Seiri    | Put Things in Order | Sort                               |
| Seiton   | Proper arrangement  | Straighten, Set in Order, Simplify |
| Seiso    | Clean               | Shine, Scrub, Sweep                |
| Seiketsu | Purity              | Standardize                        |
| Shitsuke | Commitment          | Sustain, Discipline                |

upon applying these basic principles like

>[!quote]
>"Everything has a place, Everything in its place" 

the workplace becomes easy to manage and upkeep.
