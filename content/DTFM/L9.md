# System Modeling and Simulation

A **system** is a collection of components that interact to produce outputs. 
EX: 
Mechanical:
- car suspension
- inverted pendulum
- robotic arm

 Electrical System:
- RLC circuit
- power converters
- motor drives

Thermal system:
- HVAC
- heat exchanger

Fluid System:
- hydraulics pneumatics
- pipe networks

Mixed Systems:
- like an EV which requires mechanical , electrical , thermal

### Static and Dynamic Systems

A system who's output is based on the current input of the system is known as a **Static system**

$$
y=f(u)
$$

**Dynamic systems** - output is dependent on past and current states
$$
y=f(x,u)
$$

### Classification of Dynamic Systems


| Classification  | Types                             |
| --------------- | --------------------------------- |
| Linearity       | linear system / non-linear system |
| Time Dependency | time variant / time invariant     |
| Signal Nature   |                                   |
| I/P & O/P       | SISO / MIMO                       |

## State Space Analysis

##### State and State Variables

The state of a system is the minimal set of variables that together with the inputs completely determine the future behaviour of the system.
The number of state variables in the system will give you the order of the system.

#### State Space Representation
$$
\dot{x}(t)=Ax(t)+Bu(t) \ -\text{state eqn}
$$
$$
y(t)=Cx(t)+Du(t) \ - \text{o/p eqn}
$$
where; 
        $x$ -> State vector - n x 1
        $u$ -> input vector - m x 1
        $y$ -> o/p vector - p x 1
        A -> State matrix - n x n
        B -> Input matrix - n x m
        C -> Output matrix - p x n
        D -> feed through matrix - p x m

#### Dc Motor Drive

Electrical: 
$$
L\frac{di}{dt}+Ri=V-K_{e}\omega
$$
Mechanical:
$$
J \dot{\omega} + b\omega = K_{t}i
$$
can be written as 
$$
L \dot{x_{2}} + R x_{2} = V - K_{e} x_{1}
$$
$$
\implies \dot{x_{2}} = \frac{V-K_{e}x_{1}-Rx_{2}}{L}
$$
$$
J\dot{x_{1}}+bx_{1}=K_{t}x_{2}
$$
$$
\implies \dot{x_{1}} = \frac{K_{t}x_{2}-bx_{1}}{J}
$$
$$
\boxed{\begin{bmatrix}
\dot{x_{1}} \\
\dot{x_{2}}
\end{bmatrix}
=
\begin{bmatrix}
-\frac{b}{J} & \frac{K_{t}}{J} \\
-\frac{K_{e}}{L} & -\frac{R}{L}
\end{bmatrix}
\begin{bmatrix}
x_{1} \\
x_{2}
\end{bmatrix}
+
\begin{bmatrix}
0 \\
\frac{1}{L}
\end{bmatrix}
\begin{bmatrix}
V
\end{bmatrix}}
$$
